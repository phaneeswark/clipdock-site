# ClipDock website

Public landing page for the ClipDock Android app. The site uses static HTML, CSS, and JavaScript. Open `index.html` in a browser or run `python3 -m http.server 8765` and visit `http://localhost:8765/`.

GitHub Pages publishes the root of the `main` branch. The site includes app screenshots and a theme preview, and does not ship the Android app or backend.
